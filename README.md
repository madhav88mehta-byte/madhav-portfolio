# MADHAV.EXE — Personal Portfolio

A personality-led portfolio for Madhav Mehta, built with HTML, CSS, and JavaScript and deployed on Vercel.

## Live site
https://madhav-portfolio-4nos.vercel.app/

## What is included
- **About:** student background, interests, and personal introduction
- **Experience:** campus creative work and entrepreneurial exploration
- **Featured work:** BuildSense-AI (in progress) and an IPL auction game concept
- **Projects:** public GitHub repositories loaded dynamically, with search and language filters
- **Skills and interests:** Python, AI/ML, data analysis, web development, design thinking, football, and cricket
- **Contact:** email and social profile links
- **Interactions:** draggable football-themed cover, a small penalty game, and an optional Hala Madrid music player
- **Responsive layout:** styles for desktop and mobile, plus reduced-motion support

## Run locally
No build step is required. Open `index.html` in a browser, or serve the folder with a local static server.

## Deploy
The project is static and can be deployed by importing this public repository into Vercel. The root `index.html` is the entry page.
